# Agentic Patterns Atlas v1: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship v1 of a static Astro site. It catalogs 21 agentic AI patterns in 6 families, each with an animated, step-through SVG diagram plus pseudocode and prompt templates, and has a three.js constellation atlas on the home and family pages.

**Architecture:**
- Pattern content lives in `src/content/patterns/<slug>/pattern.yaml` (metadata, code, prompts, diagram spec) and `index.mdx` (prose). Both are validated by Zod plus cross-reference checks.
- At build time, a pure compiler turns each diagram spec into a timeline, and ELK lays out the graph. Then `Diagram.astro` emits static SVG.
- A vanilla custom element `<flow-player>` animates the SVG from a single clock using a pure `frameAt()` state function.
- three.js is loaded lazily, only for the constellation hero and family headers. An SVG projection of the same stars is the fallback.

**Tech Stack:** Astro 7.3, TypeScript (strict), Zod 4, elkjs 0.12, three 0.186, astro-expressive-code 0.44, astro-pagefind 2.0, Vitest 5, Playwright 1.64, @axe-core/playwright 4.13. Fonts come from @fontsource. Node 24, npm.

**Spec:** `docs/superpowers/specs/2026-10-14-agentic-patterns-atlas-design.md`. The research source for content is `docs/research/pattern-catalog.md`.

**Deliberate refinements of the spec** (decided while planning; they take precedence over the spec's §3.2 and §5):
1. Pseudocode and prompts live inside `pattern.yaml` as `code:` and `prompts:` arrays instead of separate `.md` files. This makes `codeRef` line validation trivial and lets Expressive Code render them through its `<Code>` component.
2. The "pre-rendered static image" fallback for the constellation is a build-time **SVG projection** of the same star positions. It also serves as the no-JS view, and it holds the accessible links.
3. The social preview is one site-wide `public/og.png`, generated by a Playwright script. Per-pattern OG images move to post-v1.
4. Event timing windows (`at`) are allowed on every event type, not only `send`.

## Review Focus

These are the five likeliest real-world failures, each pinned by a test in the owning task.

1. **Scrubbing backwards, or jumping to an arbitrary time.** The diagram must show exactly the state it would have reached by playing forward to that time: dims from an earlier branch undone by a later one, hidden workers hidden again. Pinned in Task 4 (`frameAt` purity tests).
2. **A pattern whose loop or branch makes an edge dim and then taken again** (Evaluator-Optimizer fail → pass). The final `accept` edge and `output` node must not stay dimmed. Pinned in Task 4.
3. **Content typos:** an edge pointing at a missing node, a `codeRef` past the end of its code block, or a pattern missing from its family's `order`. The build must fail with the file and id named, not render a broken page. Pinned in Tasks 2 and 6.
4. **Narrow phones (360 px) and wide fan-outs** (Orchestrator-Workers, Debate). No node overlap; the layout switches to `DOWN`. Pinned in Task 5 (overlap test) and Task 16 (390 px screenshots plus a horizontal-overflow assertion).
5. **Keyboard and reduced-motion users.** Space, ← and → must work while focus is in the player but must not hijack the range input or select. Reduced motion shows each step's end state with no autoplay. Pinned in Task 8 (Playwright).

```ts
export function joinBase(base: string, path: string): string {
  const b = base.endsWith('/') ? base : base + '/';
  const p = path.startsWith('/') ? path.slice(1) : path;
  return b + p;
}
export function href(path: string): string {
  return joinBase(import.meta.env.BASE_URL ?? '/', path);
}
```

```ts
import { z } from 'zod';
import { NODE_KINDS, LABEL_MAX, SUBLABEL_MAX, DEFAULT_SIZE, type DiagramSpec, type CodeBlock } from './diagram/types';

const id = z.string().regex(/^[a-z0-9][a-z0-9-]*$/, 'ids are lowercase kebab-case');
const at = z.tuple([z.number().min(0).max(1), z.number().min(0).max(1)])
  .refine(([a, b]) => a < b, 'at[0] must be < at[1]').optional();
const level = z.enum(['low', 'medium', 'high']);
const tokenKind = z.enum(['prompt', 'tool-call', 'result', 'feedback', 'tokens']);

const eventSchema = z.discriminatedUnion('type', [
  z.object({ type: z.literal('send'), edge: id, token: z.object({ kind: tokenKind, label: z.string().max(14).optional() }), at }),
  z.object({ type: z.literal('activate'), node: id, status: z.enum(['thinking', 'calling', 'waiting', 'done', 'error']), at }),
  z.object({ type: z.literal('branch'), node: id, taken: id, notTaken: z.array(id).optional(), at }),
  z.object({ type: z.literal('appear'), node: id, at }),
  z.object({ type: z.literal('read'), node: id, at }),
  z.object({ type: z.literal('write'), node: id, at }),

export const diagramSchema = z.object({
  direction: z.enum(['RIGHT', 'DOWN']).optional(),
  groups: z.array(z.object({ id, label: z.string().min(1), children: z.array(id).min(1) })).optional(),
  nodes: z.array(z.object({
    id, kind: z.enum(NODE_KINDS), label: z.string().min(1), sublabel: z.string().optional(),
    size: z.enum(['sm', 'md', 'lg']).optional(),

export function diagramIssues(d: DiagramSpec, code: CodeBlock[]): string[] {
  const issues: string[] = [];
  const dup = (kind: string, ids: string[]) => {
    const seen = new Set<string>();
    for (const x of ids) { if (seen.has(x)) issues.push(`duplicate ${kind} id "${x}"`); seen.add(x); }
  };
  dup('node', [...d.nodes.map(n => n.id), ...(d.groups ?? []).map(g => g.id)]);
  dup('edge', d.edges.map(e => e.id));
  dup('scenario', d.scenarios.map(s => s.id));
  const nodes = new Map(d.nodes.map(n => [n.id, n]));
  const edges = new Map(d.edges.map(e => [e.id, e]));
  for (const n of d.nodes) {
    const size = n.size ?? DEFAULT_SIZE[n.kind];
    if (n.label.length > LABEL_MAX[size]) issues.push(`node "${n.id}" label "${n.label}" exceeds ${LABEL_MAX[size]} chars for size ${size}`);
    if (n.sublabel && n.sublabel.length > SUBLABEL_MAX) issues.push(`node "${n.id}" sublabel exceeds ${SUBLABEL_MAX} chars`);
  }
  for (const e of d.edges) for (const end of [e.from, e.to]) if (!nodes.has(end)) issues.push(`edge "${e.id}" references unknown node "${end}"`);
  const grouped = new Set<string>();
  for (const g of d.groups ?? []) for (const c of g.children) {
    if (!nodes.has(c)) issues.push(`group "${g.id}" references unknown node "${c}"`);
    if (grouped.has(c)) issues.push(`node "${c}" is in more than one group`);
    grouped.add(c);
  }
  const blocks = new Map(code.map(b => [b.id, b.source.replace(/\n$/, '').split('\n').length]));
  const needNode = (s: string, nodeId: string) => { if (!nodes.has(nodeId)) { issues.push(`scenario "${s}" references unknown node "${nodeId}"`); return false; } return true; };
  for (const sc of d.scenarios) {
    dup('step', sc.steps.map(s => s.id));
    const appeared = new Set<string>();
    for (const st of sc.steps) {
      if (st.codeRef) {
        const len = blocks.get(st.codeRef.block);
        const m = /^(\d+)(?:-(\d+))?$/.exec(st.codeRef.lines);
        if (len === undefined) issues.push(`step "${st.id}" references unknown code block "${st.codeRef.block}"`);
        else if (!m) issues.push(`step "${st.id}" codeRef lines "${st.codeRef.lines}" must look like "3" or "3-7"`);
        else { const a = +m[1], b = m[2] ? +m[2] : a; if (a < 1 || b < a || b > len) issues.push(`step "${st.id}" codeRef lines "${st.codeRef.lines}" out of range (block "${st.codeRef.block}" has ${len} lines)`); }
      }
      for (const ev of st.events) {
        switch (ev.type) {
          case 'send': if (!edges.has(ev.edge)) issues.push(`step "${st.id}" sends on unknown edge "${ev.edge}"`); break;
          case 'activate': needNode(sc.id, ev.node); break;
          case 'appear':
            if (needNode(sc.id, ev.node)) { if (!nodes.get(ev.node)!.hidden) issues.push(`step "${st.id}" has appear on "${ev.node}" which is not hidden`); appeared.add(ev.node); }
            break;
          case 'read': case 'write':
            if (needNode(sc.id, ev.node) && nodes.get(ev.node)!.kind !== 'memory') issues.push(`step "${st.id}" has ${ev.type} on "${ev.node}" which is not a memory node`);
            break;
          case 'branch': {
            if (!needNode(sc.id, ev.node)) break;
            for (const eid of [ev.taken, ...(ev.notTaken ?? [])]) {
              const e = edges.get(eid);
              if (!e) issues.push(`step "${st.id}" branch references unknown edge "${eid}"`);
              else if (e.from !== ev.node) issues.push(`step "${st.id}" branch edge "${eid}" is not an outgoing edge of "${ev.node}"`);
            }
          }
        }
      }
    }
    for (const n of d.nodes) if (n.hidden && !appeared.has(n.id)) issues.push(`hidden node "${n.id}" never appears in scenario "${sc.id}"`);
  }
  return issues;
}

    composesWith: z.array(id).default([]),
    confusedWith: z.array(z.object({ slug: id, difference: z.string().min(10) })).default([]),
  }).default({ composesWith: [], confusedWith: [] }),

  prompts: z.array(codeBlockSchema).min(1),

  accent: z.string().regex(/^#[0-9A-Fa-f]{6}$/),
  description: z.string().min(1),
  order: z.array(id),
  constellation: z.object({ x: z.number(), y: z.number(), z: z.number() }),

export type Pattern = z.infer<typeof patternSchema>;
export type Family = z.infer<typeof familySchema>;

export function validateCatalog(families: Family[], patterns: Pattern[]): string[] {
  const issues: string[] = [];
  const famBySlug = new Map(families.map(f => [f.slug, f]));
  const patBySlug = new Map(patterns.map(p => [p.slug, p]));
  if (famBySlug.size !== families.length) issues.push('duplicate family slug');
  if (patBySlug.size !== patterns.length) issues.push('duplicate pattern slug');
  for (const f of families) for (const s of f.order) {
    const p = patBySlug.get(s);
    if (!p) issues.push(`family "${f.slug}" order lists unknown pattern "${s}"`);
    else if (p.family !== f.slug) issues.push(`pattern "${s}" is listed in family "${f.slug}" but belongs to "${p.family}"`);
  }
  for (const p of patterns) {
    const f = famBySlug.get(p.family);
    if (!f) { issues.push(`pattern "${p.slug}" has unknown family "${p.family}"`); continue; }
    if (!f.order.includes(p.slug)) issues.push(`pattern "${p.slug}" is not listed in family "${f.slug}" order`);
    for (const r of [...p.related.composesWith, ...p.related.confusedWith.map(c => c.slug)]) {
      if (r === p.slug) issues.push(`pattern "${p.slug}" relates to itself`);
      else if (!patBySlug.has(r)) issues.push(`pattern "${p.slug}" relates to unknown pattern "${r}"`);
    }
  }
  return issues;
}
```

```ts
import type { Scenario, DiagramSpec, DiagramEvent, CodeRef } from './types';

export const DEFAULT_STEP_MS = 1200;
export interface TimedEvent { event: DiagramEvent; start: number; end: number }
export interface TimedStep { id: string; index: number; caption: string; start: number; end: number; codeRef?: CodeRef; iteration?: { n: number; of: number }; events: TimedEvent[] }
export interface Timeline { id: string; label: string; duration: number; steps: TimedStep[]; events: TimedEvent[] }

export function compileScenario(s: Scenario): Timeline {
  const steps: TimedStep[] = [];
  let t = 0;
  for (const step of s.steps) {
    const n = step.repeat ?? 1;
    const dur = step.duration ?? DEFAULT_STEP_MS;
    for (let k = 1; k <= n; k++) {
      const start = t;
      const events = step.events.map((event): TimedEvent => {
        const [a, b] = event.at ?? [0, 1];
        return { event, start: start + a * dur, end: start + b * dur };
      });
      const ts: TimedStep = { id: n > 1 ? `${step.id}#${k}` : step.id, index: steps.length, caption: step.caption, start, end: start + dur, events };
      if (step.codeRef) ts.codeRef = step.codeRef;
      if (n > 1) ts.iteration = { n: k, of: n };
      steps.push(ts);
      t = start + dur;
    }
  }
  const events = steps.flatMap(st => st.events)
    .map((e, i) => ({ e, i }))
    .sort((x, y) => x.e.start - y.e.start || x.i - y.i)
    .map(x => x.e);
  return { id: s.id, label: s.label, duration: t, steps, events };
}

export function compileDiagram(d: DiagramSpec): Timeline[] {
  return d.scenarios.map(compileScenario);
}
```

### Task 4: Frame state function (`frameAt`) and step navigation

**Files:**
- Create: `src/lib/diagram/state.ts`
- Test: `tests/unit/state.test.ts`

**Interfaces:**
- Consumes: `Timeline` from `compile.ts`; `DiagramSpec`, `TokenKind`, `ActivateStatus`, `CodeRef` from `types.ts`.
- Produces:

```ts
export type NodeState = 'idle' | 'active' | 'thinking' | 'calling' | 'waiting' | 'done' | 'error' | 'dim' | 'hidden';
export type EdgeState = 'idle' | 'active' | 'traversed' | 'dim';
export interface TokenState { edge: string; kind: TokenKind; label?: string; progress: number } // progress linear 0..1
export interface FrameState { t: number; stepIndex: number; nodes: Record<string, NodeState>; edges: Record<string, EdgeState>; tokens: TokenState[]; codeRef?: CodeRef }
export function frameAt(d: DiagramSpec, tl: Timeline, t: number): FrameState;
export function nextStepEnd(tl: Timeline, t: number): number;
export function prevStepStart(tl: Timeline, t: number): number;
```

**Semantics:**
- Clamp `t` to `[0, duration]`. Fold the events with `start ≤ t` in timeline order. An event is "live" while `t < end`.
- **send:** while live, the edge is `active` and a token is emitted with `progress = (t - start) / (end - start)`. After it ends, the edge is `traversed`.
- **activate:** while live, the node shows `status`. After it ends, it shows `done`, or `error` if the status was `error`.
- **branch:**
  - The node is `thinking` while live, `done` after.
  - If the taken edge is `dim`, it returns to `idle`, and its target node returns to `idle` if that node is `dim`.
  - Each notTaken edge becomes `dim`, and its target node becomes `dim` if it is `idle`.
- **appear:** a `hidden` node becomes `idle`.
- **read / write:** the node is `active` while live, `done` after.
- **stepIndex:** the last step with `start ≤ t`.

```ts
import type { DiagramSpec, TokenKind, ActivateStatus, CodeRef } from './types';
import type { Timeline } from './compile';

export type NodeState = 'idle' | 'active' | 'thinking' | 'calling' | 'waiting' | 'done' | 'error' | 'dim' | 'hidden';
export type EdgeState = 'idle' | 'active' | 'traversed' | 'dim';
export interface TokenState { edge: string; kind: TokenKind; label?: string; progress: number }
export interface FrameState { t: number; stepIndex: number; nodes: Record<string, NodeState>; edges: Record<string, EdgeState>; tokens: TokenState[]; codeRef?: CodeRef }

const SETTLED: Record<ActivateStatus, NodeState> = { thinking: 'done', calling: 'done', waiting: 'done', done: 'done', error: 'error' };
const EPS = 1;

export function frameAt(d: DiagramSpec, tl: Timeline, tIn: number): FrameState {
  const t = Math.min(Math.max(tIn, 0), tl.duration);
  const nodes: Record<string, NodeState> = {};
  for (const n of d.nodes) nodes[n.id] = n.hidden ? 'hidden' : 'idle';
  const edges: Record<string, EdgeState> = {};
  for (const e of d.edges) edges[e.id] = 'idle';
  const target = new Map(d.edges.map(e => [e.id, e.to]));
  const tokens: TokenState[] = [];

  for (const te of tl.events) {
    if (te.start > t) break;
    const live = t < te.end;
    const ev = te.event;
    switch (ev.type) {
      case 'send':
        if (live) {
          edges[ev.edge] = 'active';
          const tok: TokenState = { edge: ev.edge, kind: ev.token.kind, progress: (t - te.start) / (te.end - te.start) };
          if (ev.token.label) tok.label = ev.token.label;
          tokens.push(tok);
        } else edges[ev.edge] = 'traversed';
        break;
      case 'activate':
        nodes[ev.node] = live ? ev.status : SETTLED[ev.status];
        break;
      case 'branch': {
        nodes[ev.node] = live ? 'thinking' : 'done';
        if (edges[ev.taken] === 'dim') edges[ev.taken] = 'idle';
        const to = target.get(ev.taken)!;
        if (nodes[to] === 'dim') nodes[to] = 'idle';
        for (const id of ev.notTaken ?? []) {
          edges[id] = 'dim';
          const nt = target.get(id)!;
          if (nodes[nt] === 'idle') nodes[nt] = 'dim';
        }
        break;
      }
      case 'appear':
        if (nodes[ev.node] === 'hidden') nodes[ev.node] = 'idle';
        break;
      case 'read': case 'write':
        nodes[ev.node] = live ? 'active' : 'done';
        break;
    }
  }

  let stepIndex = 0;
  for (const s of tl.steps) { if (s.start <= t) stepIndex = s.index; else break; }
  const f: FrameState = { t, stepIndex, nodes, edges, tokens };
  const ref = tl.steps[stepIndex]?.codeRef;
  if (ref) f.codeRef = ref;
  return f;
}

export function nextStepEnd(tl: Timeline, t: number): number {
  const s = tl.steps.find(st => st.end > t + EPS);
  return s ? s.end : tl.duration;
}

export function prevStepStart(tl: Timeline, t: number): number {
  let r = 0;
  for (const s of tl.steps) if (s.start < t - EPS) r = s.start;
  return r;
}
```

```ts
export interface Pt { x: number; y: number }
export interface Box { x: number; y: number; w: number; h: number }

const f = (n: number) => Math.round(n * 10) / 10;
const p = (pt: Pt) => `${f(pt.x)},${f(pt.y)}`;
const dist = (a: Pt, b: Pt) => Math.hypot(b.x - a.x, b.y - a.y);

export function roundedPath(pts: Pt[], r = 10): string {
  if (pts.length < 2) return '';
  let d = `M${p(pts[0])}`;
  for (let i = 1; i < pts.length - 1; i++) {
    const a = pts[i - 1], c = pts[i], b = pts[i + 1];
    const rr = Math.min(r, dist(a, c) / 2, dist(c, b) / 2);
    const inP = { x: c.x + ((a.x - c.x) / dist(a, c)) * rr, y: c.y + ((a.y - c.y) / dist(a, c)) * rr };
    const outP = { x: c.x + ((b.x - c.x) / dist(c, b)) * rr, y: c.y + ((b.y - c.y) / dist(c, b)) * rr };
    d += ` L${p(inP)} Q${p(c)} ${p(outP)}`;
  }
  return d + ` L${p(pts[pts.length - 1])}`;
}

export function cubicPath(s: Pt, c1: Pt, c2: Pt, e: Pt): string {
  return `M${p(s)} C${p(c1)} ${p(c2)} ${p(e)}`;
}

export function loopArc(from: Box, to: Box, direction: 'RIGHT' | 'DOWN') {
  if (direction === 'RIGHT') {
    const s = { x: from.x + from.w / 2, y: from.y };
    const e = { x: to.x + to.w / 2, y: to.y };
    const lift = 48 + Math.abs(s.x - e.x) * 0.15;
    const top = Math.min(s.y, e.y) - lift;
    return { s, c1: { x: s.x, y: top }, c2: { x: e.x, y: top }, e };
  }
  const s = { x: from.x + from.w, y: from.y + from.h / 2 };
  const e = { x: to.x + to.w, y: to.y + to.h / 2 };
  const push = 48 + Math.abs(s.y - e.y) * 0.15;
  const right = Math.max(s.x, e.x) + push;
  return { s, c1: { x: right, y: s.y }, c2: { x: right, y: e.y }, e };
}

export function borderPoint(box: Box, toward: Pt): Pt {
  const cx = box.x + box.w / 2, cy = box.y + box.h / 2;
  const dx = toward.x - cx, dy = toward.y - cy;
  if (dx === 0 && dy === 0) return { x: cx, y: cy };
  const sx = dx === 0 ? Infinity : (box.w / 2) / Math.abs(dx);
  const sy = dy === 0 ? Infinity : (box.h / 2) / Math.abs(dy);
  const s = Math.min(sx, sy);
  return { x: cx + dx * s, y: cy + dy * s };
}

export function polylineMid(pts: Pt[]): Pt {
  const lens = pts.slice(1).map((q, i) => dist(pts[i], q));
  let half = lens.reduce((a, b) => a + b, 0) / 2;
  for (let i = 0; i < lens.length; i++) {
    if (half <= lens[i]) { const t = lens[i] === 0 ? 0 : half / lens[i]; return { x: pts[i].x + (pts[i + 1].x - pts[i].x) * t, y: pts[i].y + (pts[i + 1].y - pts[i].y) * t }; }
    half -= lens[i];
  }
  return pts[pts.length - 1];
}

export function offsetPolyline(pts: Pt[], d: number): Pt[] {
  const a = pts[0], b = pts[1];
  const len = dist(a, b) || 1;
  const nx = -(b.y - a.y) / len, ny = (b.x - a.x) / len;
  return pts.map(q => ({ x: q.x + nx * d + 0, y: q.y + ny * d + 0 }));
}
```

```ts
import ELK from 'elkjs/lib/elk.bundled.js';
import type { DiagramSpec, NodeSize } from './types';
import { DEFAULT_SIZE } from './types';
import { roundedPath, cubicPath, loopArc, borderPoint, polylineMid, offsetPolyline, type Pt, type Box } from './geometry';

export const NODE_DIMS: Record<NodeSize, { w: number; h: number }> = { sm: { w: 96, h: 72 }, md: { w: 136, h: 72 }, lg: { w: 176, h: 72 } };
export interface EdgeGeom { d: string; mid: Pt }
export interface DiagramLayout { width: number; height: number; nodes: Record<string, Box>; edges: Record<string, EdgeGeom>; groups: Record<string, Box & { label: string }> }

type Raw = { kind: 'poly'; pts: Pt[] } | { kind: 'arc'; s: Pt; c1: Pt; c2: Pt; e: Pt };
const elk = new ELK();
const PAD = 28;

interface ElkNode { id: string; x?: number; y?: number; width?: number; height?: number; children?: ElkNode[]; layoutOptions?: Record<string, string>; edges?: ElkEdge[] }
interface ElkEdge { id: string; sources: string[]; targets: string[]; container?: string; sections?: { startPoint: Pt; endPoint: Pt; bendPoints?: Pt[] }[] }

export async function layoutDiagram(d: DiagramSpec, direction: 'RIGHT' | 'DOWN'): Promise<DiagramLayout> {
  const dims = (id: string) => { const n = d.nodes.find(x => x.id === id)!; return NODE_DIMS[n.size ?? DEFAULT_SIZE[n.kind]]; };
  const grouped = new Set((d.groups ?? []).flatMap(g => g.children));
  const leaf = (id: string): ElkNode => ({ id, width: dims(id).w, height: dims(id).h });
  const graph: ElkNode = {
    id: 'root',
    layoutOptions: {
      'elk.algorithm': 'layered', 'elk.direction': direction, 'elk.edgeRouting': 'ORTHOGONAL',
      'elk.hierarchyHandling': 'INCLUDE_CHILDREN',
      'elk.layered.spacing.nodeNodeBetweenLayers': '64', 'elk.spacing.nodeNode': '36', 'elk.spacing.edgeNode': '20',
      'elk.layered.nodePlacement.strategy': 'BRANDES_KOEPF',
    },
    children: [
      ...(d.groups ?? []).map(g => ({ id: g.id, layoutOptions: { 'elk.padding': '[top=34,left=18,bottom=18,right=18]' }, children: g.children.map(leaf) })),
      ...d.nodes.filter(n => !grouped.has(n.id)).map(n => leaf(n.id)),
    ],
    edges: d.edges.filter(e => e.style !== 'loop').map(e => ({ id: e.id, sources: [e.from], targets: [e.to] })),
  };
  const out = (await elk.layout(graph as never)) as unknown as ElkNode;

  const abs: Record<string, Pt> = { root: { x: 0, y: 0 } };
  const nodes: Record<string, Box> = {};
  const groups: Record<string, Box & { label: string }> = {};
  const walk = (n: ElkNode, off: Pt) => {
    for (const c of n.children ?? []) {
      const pos = { x: off.x + (c.x ?? 0), y: off.y + (c.y ?? 0) };
      abs[c.id] = pos;
      const box = { ...pos, w: c.width ?? 0, h: c.height ?? 0 };
      const g = d.groups?.find(x => x.id === c.id);
      if (g) groups[g.id] = { ...box, label: g.label }; else nodes[c.id] = box;
      walk(c, pos);
    }
  };
  walk(out, { x: 0, y: 0 });

  // pos overrides (relative to the first pinned node's ELK position, so relative offsets are exact)
  const pinned = d.nodes.filter(n => n.pos);
  const moved = new Set<string>();
  if (pinned.length) {
    const anchor = nodes[pinned[0].id];
    const ox = anchor.x - pinned[0].pos!.x, oy = anchor.y - pinned[0].pos!.y;
    for (const n of pinned) { nodes[n.id] = { ...nodes[n.id], x: n.pos!.x + ox, y: n.pos!.y + oy }; moved.add(n.id); }
  }

  const raw: Record<string, Raw> = {};
  const outEdges = new Map((out.edges ?? []).map(e => [e.id, e]));
  const pairs = new Set(d.edges.filter(e => e.style !== 'loop' && d.edges.some(o => o.style !== 'loop' && o.from === e.to && o.to === e.from)).map(e => e.id));
  for (const e of d.edges) {
    const a = nodes[e.from], b = nodes[e.to];
    if (e.style === 'loop') { raw[e.id] = { kind: 'arc', ...loopArc(a, b, direction) }; continue; }
    const oe = outEdges.get(e.id);
    let pts: Pt[];
    if (!oe?.sections?.length || moved.has(e.from) || moved.has(e.to)) {
      const ca = { x: a.x + a.w / 2, y: a.y + a.h / 2 }, cb = { x: b.x + b.w / 2, y: b.y + b.h / 2 };
      pts = [borderPoint(a, cb), borderPoint(b, ca)];
    } else {
      const off = abs[oe.container ?? 'root'] ?? { x: 0, y: 0 };
      const s = oe.sections[0];
      pts = [s.startPoint, ...(s.bendPoints ?? []), s.endPoint].map(q => ({ x: q.x + off.x, y: q.y + off.y }));
    }
    if (pairs.has(e.id)) pts = offsetPolyline(pts, 6);
    raw[e.id] = { kind: 'poly', pts };
  }

  // normalize to a padded canvas
  const xs: number[] = [], ys: number[] = [];
  for (const b of [...Object.values(nodes), ...Object.values(groups)]) { xs.push(b.x, b.x + b.w); ys.push(b.y, b.y + b.h); }
  for (const r of Object.values(raw)) for (const q of r.kind === 'poly' ? r.pts : [r.s, r.c1, r.c2, r.e]) { xs.push(q.x); ys.push(q.y); }
  const minX = Math.min(...xs) - PAD, minY = Math.min(...ys) - PAD;

  const shBox = <T extends Box>(b: T): T => ({ ...b, x: b.x - minX, y: b.y - minY });
  for (const k in nodes) nodes[k] = shBox(nodes[k]);
  for (const k in groups) groups[k] = shBox(groups[k]);
  const edges: Record<string, EdgeGeom> = {};
  for (const [k, r] of Object.entries(raw)) {
    if (r.kind === 'poly') { const pts = r.pts.map(sh); edges[k] = { d: roundedPath(pts, 10), mid: polylineMid(pts) }; }
    else {
      const [s, c1, c2, e] = [r.s, r.c1, r.c2, r.e].map(sh);
      edges[k] = { d: cubicPath(s, c1, c2, e), mid: { x: 0.125 * s.x + 0.375 * c1.x + 0.375 * c2.x + 0.125 * e.x, y: 0.125 * s.y + 0.375 * c1.y + 0.375 * c2.y + 0.125 * e.y } };
    }
  }
  return { width: Math.ceil(Math.max(...xs) - minX + PAD), height: Math.ceil(Math.max(...ys) - minY + PAD), nodes, edges, groups };
}
```

```ts
import { validateCatalog, type Family, type Pattern } from './schema';

export interface Catalog {
  families: Family[]; patterns: Pattern[]; bySlug: Map<string, Pattern>;
  family(slug: string): Family; patternsOf(familySlug: string): Pattern[];
  neighbors(slug: string): { prev?: Pattern; next?: Pattern };
}

export function buildCatalog(familiesIn: Family[], patternsIn: Pattern[]): Catalog {
  const issues = validateCatalog(familiesIn, patternsIn);
  if (issues.length) throw new Error(`Content catalog is invalid:\n  - ${issues.join('\n  - ')}`);
  const families = [...familiesIn].sort((a, b) => a.rank - b.rank);
  const bySlug = new Map(patternsIn.map(p => [p.slug, p]));
  const famMap = new Map(families.map(f => [f.slug, f]));
  const patternsOf = (fs: string) => famMap.get(fs)!.order.map(s => bySlug.get(s)!);
  const patterns = families.flatMap(f => patternsOf(f.slug));
  return {
    families, patterns, bySlug,
    family(slug) { const f = famMap.get(slug); if (!f) throw new Error(`unknown family ${slug}`); return f; },
    patternsOf,
    neighbors(slug) {
      const p = bySlug.get(slug)!; const list = patternsOf(p.family); const i = list.findIndex(x => x.slug === slug);
      return { prev: list[i - 1], next: list[i + 1] };
    },
  };
}

let memo: Promise<Catalog> | undefined;
export function getCatalog(): Promise<Catalog> {
  memo ??= (async () => {
    const { getCollection } = await import('astro:content');
    const fams = (await getCollection('families')).map(e => e.data as Family);
    const pats = (await getCollection('patterns')).map(e => e.data as Pattern);
    return buildCatalog(fams, pats);
  })();
  return memo;
}
```

```mdx
## Problem

First drafts are rarely the best an LLM can do. A model asked to write, translate or code in one shot will miss requirements it would have caught had it reread its own work, but a single prompt gives it no chance to reread.

## How it works

A <NodeRef id="generator">generator</NodeRef> produces a draft. An <NodeRef id="evaluator">evaluator</NodeRef> (a second model, or the same model under a reviewer prompt) checks it against explicit criteria and either passes it or returns a concrete critique. The critique goes back to the generator as context for the next draft. The loop ends when the evaluator passes the draft or a round budget runs out, and the result goes to the <NodeRef id="output">output</NodeRef>.

The criteria are what make this work: the evaluator needs a bar it can actually check, such as "every claim is cited", "the code passes these tests" or "the tone matches this example".

## When to use

- You can state clear evaluation criteria, ideally checkable ones.
- Revising measurably improves the result: literary translation, complex search, code that must pass tests.
- A human could give useful feedback on the draft, so a model probably can too.

## When to avoid

- There are no criteria to judge against: the loop just churns.
- The first draft is usually good enough: you pay two or three times the latency for nothing.
- The evaluator and generator share a blind spot. Prefer tool-grounded checks (tests, validators) over pure opinion.

## Trade-offs

Each round costs at least two model calls, so latency and cost grow with the number of rounds. Always cap the rounds. Quality gains usually flatten after two or three rounds.

## Failure modes

- **Endless loop:** the evaluator never passes the draft. Mitigate with a round budget and a "best so far" fallback.
- **Rubber-stamping:** an evaluator that's too lenient passes everything. Make the prompt strict and the criteria explicit.
- **Oscillation:** fixes for one critique break an earlier one. Pass the full critique history, not just the last one.
```

```ts
  private visible = false;
  private raf = 0;
  private last = 0;
  private lastStep = -1;
  private reduced = matchMedia('(prefers-reduced-motion: reduce)').matches;
  private views: View[] = [];
  private nodeEls = new Map<string, Element[]>();
  private edgeEls = new Map<string, Element[]>();
  private scrub?: HTMLInputElement;
  private scrubbing = false;
  private onDoc = (e: Event) => this.onNodeRef(e as CustomEvent<{ node: string | null }>);
  private onVis = () => this.ensureLoop();

  get compact() { return this.hasAttribute('compact'); }

  connectedCallback() {
    const json = this.querySelector('script[data-diagram]');
    if (!json?.textContent) return;
    this.data = JSON.parse(json.textContent);
    this.tl = this.data.timelines[0];
    this.querySelectorAll('[data-node]').forEach(el => this.push(this.nodeEls, (el as HTMLElement).dataset.node!, el));
    this.querySelectorAll('path.edge[data-edge], text.edge-label[data-edge]').forEach(el => this.push(this.edgeEls, (el as HTMLElement).dataset.edge!, el));
    this.querySelectorAll<SVGSVGElement>('svg.diagram-svg').forEach(svg => {
      const paths = new Map<string, SVGPathElement>();
      svg.querySelectorAll<SVGPathElement>('path.edge').forEach(p => paths.set(p.dataset.edge!, p));
      const view: View = { svg, layer: svg.querySelector('g.tokens')!, paths, lengths: new Map(), pool: [], active: false };
      this.views.push(view);
      new ResizeObserver(([entry]) => { view.active = entry.contentRect.width > 0; if (view.active) this.render(); }).observe(svg);
    });
    this.classList.add('is-enhanced');
    this.setAttribute('data-playing', 'false');
    this.querySelector('.fp-controls')?.removeAttribute('hidden');
    this.bindControls();
    this.syncScenarioLists();
    new IntersectionObserver(([e]) => {
      this.visible = e.isIntersecting;
      if (this.visible && !this.userControl && !this.reduced && !this.playing) this.setPlaying(true);
      this.ensureLoop();
    }, { threshold: 0.3 }).observe(this);
    document.addEventListener('visibilitychange', this.onVis);
    if (!this.compact) document.addEventListener('noderef', this.onDoc);
    this.render();
  }

  disconnectedCallback() {
    cancelAnimationFrame(this.raf);
    document.removeEventListener('visibilitychange', this.onVis);
    document.removeEventListener('noderef', this.onDoc);
  }

  private push(m: Map<string, Element[]>, k: string, el: Element) { const a = m.get(k); if (a) a.push(el); else m.set(k, [el]); }

  private bindControls() {
    const q = <T extends Element>(s: string) => this.querySelector<T>(s);
    q<HTMLButtonElement>('[data-action="play"]')?.addEventListener('click', () => this.togglePlay());
    q<HTMLButtonElement>('[data-action="next"]')?.addEventListener('click', () => this.next());
    q<HTMLButtonElement>('[data-action="prev"]')?.addEventListener('click', () => this.prev());
    this.scrub = q<HTMLInputElement>('[data-scrub]') ?? undefined;
    this.scrub?.addEventListener('input', () => { this.take(); this.setPlaying(false); this.t = (+this.scrub!.value / 1000) * this.tl.duration; this.render(); });
    this.scrub?.addEventListener('pointerdown', () => (this.scrubbing = true));
    this.scrub?.addEventListener('pointerup', () => (this.scrubbing = false));
    q<HTMLSelectElement>('[data-speed]')?.addEventListener('change', e => (this.speed = +(e.target as HTMLSelectElement).value));
    q<HTMLSelectElement>('[data-scenario]')?.addEventListener('change', e => {
      this.tl = this.data.timelines[+(e.target as HTMLSelectElement).value];
      this.t = 0; this.lastStep = -1; this.syncScenarioLists(); this.render();
    });
    q<HTMLElement>('.diagram-stage')?.addEventListener('keydown', e => {
      const tag = (e.target as HTMLElement).tagName;
      if (tag === 'INPUT' || tag === 'SELECT') return;
      const k = e.key;
      if (k === ' ' || k === 'Spacebar') { e.preventDefault(); this.togglePlay(); }
      else if (k === 'ArrowRight') { e.preventDefault(); this.next(); }
      else if (k === 'ArrowLeft') { e.preventDefault(); this.prev(); }
      else if (k === 'Home') { e.preventDefault(); this.take(); this.setPlaying(false); this.t = 0; this.render(); }
      else if (k === 'End') { e.preventDefault(); this.take(); this.setPlaying(false); this.t = this.tl.duration; this.render(); }
    });
  }

  private take() { this.userControl = true; this.stopAt = null; }

  private togglePlay() {
    this.take();
    if (!this.playing && this.t >= this.tl.duration) this.t = 0;
    this.setPlaying(!this.playing);
  }

  private next() {
    this.take();
    const target = nextStepEnd(this.tl, this.t);
    if (this.reduced) { this.setPlaying(false); this.t = target; this.render(); return; }
    this.stopAt = target; this.setPlaying(true);
  }

  private prev() {
    this.take(); this.setPlaying(false);
    this.t = prevStepStart(this.tl, this.t); this.render();
  }

  private setPlaying(v: boolean) {
    this.playing = v;
    this.setAttribute('data-playing', String(v));
    const b = this.querySelector('[data-action="play"]');
    b?.setAttribute('aria-pressed', String(v));
    b?.setAttribute('aria-label', v ? 'Pause' : 'Play');
    this.ensureLoop();
  }

  private ensureLoop() {
    const run = this.playing && this.visible && !document.hidden;
    if (run && !this.raf) { this.last = performance.now(); this.raf = requestAnimationFrame(this.tick); }
    if (!run && this.raf) { cancelAnimationFrame(this.raf); this.raf = 0; }
  }

  private tick = (now: number) => {
    const dt = Math.min(now - this.last, 100);
    this.last = now;
    let t = this.t + dt * this.speed;
    if (this.stopAt !== null && t >= this.stopAt) { t = this.stopAt; this.stopAt = null; this.t = t; this.render(); this.raf = 0; this.setPlaying(false); return; }
    if (t >= this.tl.duration) {
      if (!this.userControl) { if (t >= this.tl.duration + HOLD_MS) t = 0; }
      else { this.t = this.tl.duration; this.render(); this.raf = 0; this.setPlaying(false); return; }
    }
    this.t = t;
    this.render();
    this.raf = requestAnimationFrame(this.tick);
  };

  private shownT(): number {
    if (!this.reduced) return this.t;
    const f = frameAt(this.data.spec, this.tl, this.t);
    const step = this.tl.steps[f.stepIndex];
    return this.t >= this.tl.duration ? this.tl.duration : step.end - 0.001;
  }

  private render() {
    if (!this.data) return;
    const f = frameAt(this.data.spec, this.tl, this.shownT());
    for (const [id, s] of Object.entries(f.nodes)) for (const el of this.nodeEls.get(id) ?? []) if (el.getAttribute('data-state') !== s) el.setAttribute('data-state', s);
    for (const [id, s] of Object.entries(f.edges)) for (const el of this.edgeEls.get(id) ?? []) if (el.getAttribute('data-state') !== s) el.setAttribute('data-state', s);
    for (const v of this.views) if (v.active) this.drawTokens(v, f.tokens);
    if (this.scrub && !this.scrubbing) this.scrub.value = String(Math.round((Math.min(this.t, this.tl.duration) / this.tl.duration) * 1000));
    if (f.stepIndex !== this.lastStep) this.onStep(f);
  }

  private drawTokens(v: View, tokens: TokenState[]) {
    while (v.pool.length < tokens.length) v.pool.push(this.makeToken(v.layer));
    v.pool.forEach((g, i) => {
      const tok = tokens[i];
      if (!tok) { g.setAttribute('display', 'none'); return; }
      const path = v.paths.get(tok.edge);
      if (!path) { g.setAttribute('display', 'none'); return; }
      let len = v.lengths.get(tok.edge);
      if (len === undefined) { len = path.getTotalLength(); v.lengths.set(tok.edge, len); }
      g.removeAttribute('display');
      g.setAttribute('data-kind', tok.kind);
      const parts = g.children;
      const head = path.getPointAtLength(ease(tok.progress) * len);
      parts[3].setAttribute('transform', `translate(${head.x},${head.y})`);
      TRAIL.forEach((lag, k) => {
        const pt = path.getPointAtLength(ease(Math.max(0, tok.progress - lag)) * len);
        parts[k].setAttribute('transform', `translate(${pt.x},${pt.y})`);
      });
      const label = parts[4] as SVGTextElement;
      label.textContent = tok.label ?? '';
      label.setAttribute('transform', `translate(${head.x},${head.y - 10})`);
    });
  }

  private makeToken(layer: SVGGElement): SVGGElement {
    const g = document.createElementNS(NS, 'g');
    g.setAttribute('class', 'token');
    [2.6, 3.2, 3.8].forEach((r, i) => { const c = document.createElementNS(NS, 'circle'); c.setAttribute('r', String(r)); c.setAttribute('class', 'trail'); c.setAttribute('opacity', String(0.25 + i * 0.2)); g.appendChild(c); });
    const head = document.createElementNS(NS, 'circle'); head.setAttribute('r', '4.2'); head.setAttribute('class', 'head'); g.appendChild(head);
    const text = document.createElementNS(NS, 'text'); text.setAttribute('text-anchor', 'middle'); g.appendChild(text);
    layer.appendChild(g);
    return g;
  }

  private onStep(f: FrameState) {
    this.lastStep = f.stepIndex;
    this.setAttribute('data-step-index', String(f.stepIndex));
    const step = this.tl.steps[f.stepIndex];
    const cap = this.querySelector('.fp-caption');
    if (cap) cap.textContent = step.caption + (step.iteration ? ` (round ${step.iteration.n} of ${step.iteration.of})` : '');
    const counter = this.querySelector('.fp-counter');
    if (counter) counter.textContent = `Step ${f.stepIndex + 1} / ${this.tl.steps.length}`;
    this.querySelectorAll(`ol.fp-captions[data-scenario="${this.tl.id}"] li`).forEach(li => {
      if ((li as HTMLElement).dataset.stepIndex === String(f.stepIndex)) li.setAttribute('aria-current', 'step'); else li.removeAttribute('aria-current');
    });
    this.dispatchEvent(new CustomEvent('flowstep', { bubbles: true, detail: { uid: this.dataset.uid, stepIndex: f.stepIndex, codeRef: f.codeRef } }));
  }

  private syncScenarioLists() {
    this.querySelectorAll<HTMLElement>('.fp-scenario-steps').forEach(el => {
      if (el.dataset.scenario === this.tl.id) el.removeAttribute('data-inactive'); else el.setAttribute('data-inactive', '');
    });
  }

  private onNodeRef(e: CustomEvent<{ node: string | null }>) {
    this.querySelectorAll('.node.is-ref').forEach(el => el.classList.remove('is-ref'));
    if (e.detail.node) for (const el of this.nodeEls.get(e.detail.node) ?? []) el.classList.add('is-ref');
  }
}

if (!customElements.get('flow-player')) customElements.define('flow-player', FlowPlayer);
```

```ts
import type { Family, Pattern } from './schema';

export interface Star { slug: string; name: string; family: string; color: string; x: number; y: number; z: number }
export interface ConstellationData { stars: Star[]; links: [string, string][]; families: { slug: string; name: string; color: string; x: number; y: number; z: number }[] }

function hash(s: string): number { let h = 2166136261; for (let i = 0; i < s.length; i++) { h ^= s.charCodeAt(i); h = Math.imul(h, 16777619); } return h >>> 0; }
function rng(seed: number) { return () => { seed |= 0; seed = (seed + 0x6D2B79F5) | 0; let t = Math.imul(seed ^ (seed >>> 15), 1 | seed); t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t; return ((t ^ (t >>> 14)) >>> 0) / 4294967296; }; }
const r3 = (n: number) => Math.round(n * 1000) / 1000;

export function buildConstellation(families: Family[], patternsOf: (familySlug: string) => Pattern[]): ConstellationData {
  const stars: Star[] = []; const links: [string, string][] = [];
  for (const f of families) {
    const rand = rng(hash(f.slug));
    const ps = patternsOf(f.slug);
    ps.forEach((p, i) => {
      stars.push({ slug: p.slug, name: p.name, family: f.slug, color: f.accent,
        x: r3(f.constellation.x + (rand() - 0.5) * 2.4), y: r3(f.constellation.y + (rand() - 0.5) * 1.8), z: r3(f.constellation.z + (rand() - 0.5) * 2.4) });
      if (i > 0) links.push([ps[i - 1].slug, p.slug]);
    });
  }
  return { stars, links, families: families.map(f => ({ slug: f.slug, name: f.name, color: f.accent, ...f.constellation })) };
}

export function project(p: { x: number; y: number; z: number }, yaw: number, pitch: number) {
  const cy = Math.cos(yaw), sy = Math.sin(yaw), cp = Math.cos(pitch), sp = Math.sin(pitch);
  const x1 = p.x * cy + p.z * sy, z1 = -p.x * sy + p.z * cy;
  const y2 = p.y * cp - z1 * sp, z2 = p.y * sp + z1 * cp;
  return { x: x1 + 0, y: y2 + 0, depth: z2 + 0 };
}
```

- [ ] **Step 1: The budget script**

`scripts/check-budget.mjs`:

```js
import { readFileSync, readdirSync, statSync } from 'node:fs';
import { join } from 'node:path';
import { gzipSync } from 'node:zlib';

const DIST = 'dist', PAGE_LIMIT = 15 * 1024, SCENE_LIMIT = 200 * 1024;
const walk = d => readdirSync(d).flatMap(f => { const p = join(d, f); return statSync(p).isDirectory() ? walk(p) : [p]; });
const gz = p => gzipSync(readFileSync(p)).length;
const files = walk(DIST);
const jsFiles = files.filter(f => f.endsWith('.js') && !f.includes(`${DIST}/pagefind/`));
const isScene = f => /constellation-scene/.test(f) || /three/.test(readFileSync(f, 'utf8').slice(0, 2000)) && gz(f) > 60 * 1024;
const sceneChunks = jsFiles.filter(isScene);
const sceneSize = sceneChunks.reduce((a, f) => a + gz(f), 0);
let failed = false;
if (sceneSize > SCENE_LIMIT) { console.error(`✗ three.js scene ${(sceneSize / 1024).toFixed(1)} KB > 200 KB`); failed = true; }
else console.log(`✓ three.js scene ${(sceneSize / 1024).toFixed(1)} KB`);

// statically referenced scripts per page (modulepreload + script src + imports inside those modules)
const resolve = src => join(DIST, src.replace(/^\/+/, '').replace(/^[^/]*?(_astro\/)/, '$1'));
const importsOf = f => [...readFileSync(f, 'utf8').matchAll(/(?:^|[;\s])import\s*(?:[^'"]*from\s*)?["']\.\/([^"']+\.js)["']/g)].map(m => join(f, '..', m[1]));
for (const html of files.filter(f => f.endsWith('.html'))) {
  const src = readFileSync(html, 'utf8');
  const entry = [...src.matchAll(/<script[^>]+src="([^"]+\.js)"/g), ...src.matchAll(/<link[^>]+rel="modulepreload"[^>]+href="([^"]+\.js)"/g)].map(m => resolve(m[1]));
  const seen = new Set(); const stack = [...entry];
  while (stack.length) { const f = stack.pop(); if (seen.has(f) || isScene(f)) continue; seen.add(f); try { stack.push(...importsOf(f)); } catch {} }
  const inline = [...src.matchAll(/<script(?![^>]*src=)(?![^>]*application\/json)[^>]*>([\s\S]*?)<\/script>/g)].reduce((a, m) => a + gzipSync(m[1]).length, 0);
  const total = [...seen].reduce((a, f) => a + gz(f), 0) + inline;
  const rel = html.slice(DIST.length);
  if (total > PAGE_LIMIT) { console.error(`✗ ${rel} ${(total / 1024).toFixed(1)} KB > 15 KB`); failed = true; }
  else console.log(`✓ ${rel} ${(total / 1024).toFixed(1)} KB`);
}
process.exit(failed ? 1 : 0);
```

Run `npm run build && npm run budget`. Expected: every page passes. If a page fails, find which module is heavy (e.g. `npx vite-bundle-visualizer` or inspect the `_astro` chunks) and fix the cause; do not raise the limit. If the script mis-attributes chunks (for example, Astro inlines small scripts), fix the script's detection and note how in a comment.
